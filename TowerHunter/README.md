# TowerHunter — навигатор Ancient Ruins / Ancient Towers (Palworld, UE4SS Lua)

Мод для мини-башен **Ancient Ruins (Ancient Towers)**, разбросанных по карте:
те самые, что закрыты барьером и открываются мини-игрой / разбиванием камней
вокруг / боем с палом, а внутри стоит стела (древний алтарь), с которой
нажатием F берётся награда.

> **v6.0:** мини-игры замков (отмычка / рулетка / росчерк) теперь
> **выигрываются автоматически** через ~0.8 с после открытия (модуль
> `Scripts/minigame.lua`, там настраивается и отключается). Метки MARK
> привязаны к стабильным «якорям» башни — **не теряются** ни после
> перезахода в игру, ни после зачистки башни.

Мод — навигатор + авто-скик мини-игр замков: он показывает все башни мира,
телепортирует к ним, ведёт ваш личный чек-лист «посетил» и выигрывает
мини-игры замков. Камни и бои с палами вы по-прежнему проходите сами, стелы
лутаете сами.

**F6** открывает панель со **всеми башнями мира**. У каждой:

- **[v] MARK** — ваш чекбокс «посетил» (сохраняется в локальный файл, переживает перезаходы и зачистку башни);
- **TP** — телепорт рядом с башней (поэтапный, ждёт прогрузки рельефа,
  проверяет землю трассировкой — не проваливаетесь под текстуру);
- статус: стена поднята/упала, стела есть/облутана, расстояние до вас.

**Мини-игры замков** (отмычка / рулетка / росчерк) выигрываются автоматически:
открыл по F → ~0.8 с → виджет закрылся сам → замок открыт. Настраивается и
отключается в `Scripts/minigame.lua`.

Сверху: **RESCAN** (пересканировать мир), **TP NEAREST** (к первой
незаконченной башне), **SORT** (по расстоянию / типу / статусу), пагинация.
При открытии панели она показывает страницу башни, у которой вы стоите.

Цветовая полоса строки: **золотая** — помечено вами, **зелёная** — башня
открыта, **красная** — ещё закрыта, **фиолетовая** — статус неизвестен.

## Установка

Требуется [UE4SS](https://github.com/UE4SS/UE4SS) (обычно уже стоит вместе
с другими Lua-модами).

1. скопируйте папку `TowerHunter` в `Pal\Binaries\Win64\Mods\` (или в
   `ue4ss\Mods\` — куда установлен UE4SS);
2. убедитесь, что в папке есть `enabled.txt`;
3. в игре нажмите **F6**.

Обновление: просто перезапишите файлы. Прогресс-файл
(`towerhunter_progress.txt`) совместим между версиями — метки не теряются.

## Управление

- **F6** — открыть/закрыть панель (при открытии мир пересканируется);
- **ESC** — закрыть панель;
- чат: `!th` — панель, `!th rescan` — пересканировать, `!th stats` —
  статистика, `!th help` — справка.

## Конфиг (начало `Scripts/main.lua`)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `OpenKey` | `"F6"` | клавиша панели |
| `TeleportOffset` | `900` | на каком расстоянии от центра башни вы появляетесь (юниты; 100 = 1 м) |
| `GroupRadius` | `6000` | радиус, в котором стела/барьер/точка ФТ считаются принадлежащими башне |
| `PageSize` | `7` | строк на странице |
| `ClusterRadius` | `4000` | расстояние, ближе которого гиммики считаются одной башней |
| `CooldownMs` | `400` | минимальная пауза между действиями панели |
| `ChatPrefix` | `"!"` | префикс чат-команд |

Прогресс чекбоксов хранится в `Mods/TowerHunter/towerhunter_progress.txt`.
Ключ метки — координаты «якорей» башни (стела / барьер / точка быстрого
перемещения): эти объекты не исчезают при зачистке башни, поэтому метки
стабильны между сессиями. Файл совместим с прогрессом от старых версий мода.

## Конфиг мини-игр (начало `Scripts/minigame.lua`)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `Enabled` | `true` | главный выключатель авто-скика мини-игр |
| `DelayMs` | `800` | сколько мс мини-игра открыта перед победой |
| `CloseCheckMs` | `500` | через сколько мс после победы принудительно закрыть виджет |
| `Games` | все `true` | вкл/выкл отдельных игр (`picking` / `gauge` / `onestroke`) |
| `GaugeNatural` | `true` | рулетка: побеждать через `Model:SendResult(true)` как виджет |

Мини-игры побеждаются вызовом тех же нативных функций, что игра вызывает при
честной победе (`OnReceiveSuccessPicking` / `OnReceiveGameSuccess` /
`Model:SendResult(true)`), а зависший виджет закрывается штатным `Close()`
(тот же путь, что клавиша ESC).

## Принципы работы (почему мод «тихий»)

- **Только события, ноль фонового поллинга.** Панель, телепорт и чат
  реагируют на нажатия клавиш и чат-событие; мир сканируется по требованию
  (RESCAN / открытие панели). Мод не тикает в фоне вообще.
- **Вне живого мира — ноль нативных вызовов.** Все указатели на объекты
  мира умирают при выходе в меню; мод сбрасывает кэши при входе в мир и
  никогда не трогает игровые объекты «снаружи».
- **Вход в мир — чистый Lua.** При загрузке мира закрывается только наша
  собственная панель; виджеты игры не трогаются никогда.
- **Мир почти только читается.** Действия мода: телепорт (через штатную
  систему передвижения), запись вашего файла прогресса и вызов нативных
  функций завершения мини-игр (тех же, что игра вызывает при честной победе).
  Лут стел, камни и бои с палами мод не трогает — состояние сохранений
  консистентно.

Совместимость: мод не переопределяет никаких игровых ассетов и не
конфликтует с pak-модами (включая скипы мини-игр) и другими Lua-модами.

## Известные ограничения

- Башни, открытые «наполовину» (несколько гиммиков), показывают счётчик
  `N/M` в статусе.
- Статус стелы читается по флагу `bPickedInClient` — если игра обновляет
  его с задержкой, строка подтянется после RESCAN.
- TP всегда ставит вас **рядом** с башней (не внутрь) — чтобы не
  заблокироваться в мешах.
