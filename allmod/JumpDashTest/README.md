# JumpDashTest v2 — тестовый мод (UE4SS / Palworld)

Тестовая проверка механик перед интеграцией в основной мод.

## Что изменилось в v2 (по итогам теста v1)

1. **Убраны ВСЕ циклы и опросы.** В v1 был опрос раз в секунду
   (`FindAllOf` + попытки хука в цикле) — спам в консоль и нагрузка.
   Теперь мод **в простое не выполняет ни одной инструкции**: всё событийное.
2. **Исправлен фатальный баг «игрок найден: nil» каждую секунду.** Причина:
   сравнение объектов по идентичности обёрток (`~=`), а UE4SS возвращает
   новые обёртки при каждом обращении. Теперь идентичность — только по
   `GetAddress()`.
3. **Исправлен «прыгаю в космос после снятия предмета».** Это было следствие
   бага №2: мод каждую секунду «терял» игрока, сбрасывал состояние и не знал,
   что применял множитель. Плюс добавлена страховка: сверка/откат ровно
   в момент прыжка (хук `Jump`), так что даже если событие снятия предмета
   пролетит мимо хуков — первый же прыжок вернёт ваниль.
4. **Проверка строго по пассивке** (как и было задумано): `HasSkill` по
   компоненту пассивок игрока. Работает для ЛЮБЫХ предметов с пассивкой —
   ванильных ботинок/пояса или предметов, которым пассивку выдал другой мод.
   Нет пассивки → мод ничего не меняет.

## Что делает

| Пассивка | Предметы (ID) | Что меняем | Ваниль | Как |
|---|---|---|---|---|
| `AirDash` (104) | Air Dash Boots (`Accessory_AirDash1..3`), Air Walker Mk-I/II/III/EX | **дистанция** рывка (Ctrl в воздухе) | 400 см / 0.5 с | `Const_MoveDistance` в `BP_ActionAirDashBase:OnBeginAction` |
| `JumpCount_Increase` (81) | Double/Triple/Quad Jump Boots, Air Walker | **число доп. прыжков** | +1/+2/+3 | `CharacterMovement.JumpMaxCount` |
| `JumpPower_Increase` (80) | Anti-Gravity Belt (`Accessory_JumpPower_Increase`) | **силу (высоту) прыжка** | +25% | `SetJumpZVelocityMultiplier("JumpDashTest", x)` |

У Jump Boots меняется только количество прыжков — отдельной высоты доп.
прыжка в игре нет. Высоту меняет именно пояс (пассивка `JumpPower_Increase`).

Эффект «пружины» у рывка сохраняется: кривая рывка не меняется, при
увеличении дистанции пропорционально растёт скорость (x10 = 40 м за те же
0.5 с). Импульс сохраняется в конец рывка — разгон продолжится планером.

## События (всё, что «живёт» в моде)

```
ClientRestart (вход/респавн)  -> привязка к игроку (1 строка лога) + сверка + 1 попытка хука рывка
OnStart/OnEndSkillEffect      -> надел/снял предмет: мгновенное применение/откат
Jump (момент прыжка)          -> бесшумная сверка/откат (страховка «космоса»)
OnBeginAction (BP рывка)      -> параметры рывка; хук ставится РОВНО 1 раз
OnReceivedChat                -> команды !jd (тест)
```

Хук рывка ставится один раз: при загрузке → при ClientRestart → (страховка)
при создании первого объекта рывка через `NotifyOnNewObject`. Повторных
попыток и таймеров нет. Регистрация `FindAllOf` — только если контекст
потерян (смерть/респавн мимо ClientRestart), не чаще каждой 10-й попытки
и только по факту события (прыжок/дэш).

## Установка

```
Pal/Binaries/Win64/Mods/JumpDashTest/enabled.txt
Pal/Binaries/Win64/Mods/JumpDashTest/config.txt
Pal/Binaries/Win64/Mods/JumpDashTest/Scripts/main.lua
```

## Конфиг — `config.txt`

```ini
Enabled = true            ; false = возврат к ванили
AirDashDistanceMult = 5.0 ; 1.0 = ваниль (4 м); 10.0 = 40 м
AirDashTimeMult     = 1.0 ; 1.0 = ваниль (0.5 с); 0.5 = вдвое резче
ExtraJumpCount      = 5   ; доп. прыжки (Jump Boots)
JumpPowerMult       = 2.0 ; сила прыжка (пояс); высота ~ x^2
```

## Команды в чате

```
!jd            — статус (пассивки, значения, счётчики событий, состояние хуков)
!jd dash 10    — множитель дистанции рывка
!jd time 0.5   — множитель времени рывка
!jd jumps 8    — число доп. прыжков
!jd power 3    — множитель силы прыжка
!jd on/off     — вкл/выкл мод (мгновенный возврат к ванили)
!jd skills     — дамп всех активных пассивок игрока
!jd save|reload|debug|help
```

## Чеклист теста

1. Вход в мир: одна строка `привязка к игроку: ... @ 0x...` и одна строка
   `хук рывка зарегистрирован (...)`. Больше в простое мод не пишет ничего.
2. Air Dash Boots: прыжок → Ctrl в воздухе → рывок длиннее (x5 = 20 м).
   Снял → следующий рывок снова микро.
3. Jump Boots: `!jd` покажет `JumpMaxCount=6`. Снял → при следующем прыжке
   откат к ванили (в консоли `ПРЫЖКИ: возврат к ванили`).
4. Пояс: прыжок заметно выше. Снял → **первый же прыжок** после снятия
   должен быть обычным (это и есть фикс «космоса»).
5. Твой мод-выдаватель пассивок: выдай любому предмету пассивку AirDash /
   JumpPower — эффект должен работать так же, пока предмет надет.
6. `!jd` после теста: пришли вывод (пассивки, счётчики, состояние хуков) —
   по счётчикам видно, какие хуки реально срабатывают в игре.

## Известные ограничения

- `OnStart/OnEndSkillEffect` — нативные функции: если игра зовёт их мимо
  ProcessEvent, события не приходят — тогда всё применяет/откатывает
  сверка в момент прыжка (Jump-хук) и ClientRestart. Для дэша это не важно:
  параметры пишет хук `OnBeginAction` (Blueprint, ProcessEvent-путь).
- Если игра считает доп. прыжки не через `JumpMaxCount`, количество не
  изменится (в `!jd` будет видно JumpMaxCount=6 при ванильном числе прыжков) —
  запасной вариант: правка `Value` в `SkillInfos`, добавим по результатам.
- Кооп: мод меняет параметры локального игрока; чужие контроллеры
  игнорируются (проверка `IsLocalPlayerController`).
- Верховая езда: пока верхом, JumpMaxCount не трогаем (у маунта своя логика).
