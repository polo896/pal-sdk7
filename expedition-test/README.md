# ExpeditionHubTest v0.4 — менеджер экспедиций (Palworld 0.4.11, UE4SS Lua)

**F6 — панель. 4 кнопки. Всё.** Не для публикации (тестовая стадия).

## Что изменилось в v0.4 (главное — стабильность)

- **Найдена причина крашей v0.3**: система «захвата» UI-моделей держала ссылки на
  объекты, которые игра уничтожала → висячие указатели → EXCEPTION_ACCESS_VIOLATION
  (pcall такое не ловит — это нативный краш). **Захват удалён полностью.**
- **Новое правило мода: НИ ОДНОЙ ссылки на объекты игры между действиями.**
  Станции переищиваются заново при каждом действии. Никаких NotifyOnNewObject
  (кроме проверенного хука смены мира). Никаких фоновых таймеров.
- **Механизм запуска подтверждён тестом v0.3**: `RequestSelectAuto_ServerInternal(playerId)`
  назначает палов, `RequestStartMission_ServerInternal(playerId)` стартует экспедицию
  (playerId = 259 у тебя). Станция должна иметь выбранную миссию.
- Стало 4 кнопки вместо 13.

## Установка

```
Pal\Binaries\Win64\ue4ss\Mods\ExpeditionHubTest\

```

(перезапиши `scripts\main.lua`)

## Панель (F6)

- `<< PREV` / `NEXT >>` — выбор станции (все станции со всех баз)
- Инфо станции: состояние / миссия / база / палы / сундук
- **4 кнопки:**

| Кнопка | Что делает |
|---|---|
| **ОТКРЫТЬ UI ЭКСПЕДИЦИИ (как в игре)** | закрывает нашу панель и открывает игровой UI выбранной станции — выбери там миссию и палов как обычно |
| **ЗАПУСК — ПОВТОРИТЬ МИССИЮ** | не подходя к станции: авто-назначение палов + запуск той миссии, что на станции выбрана (если миссии нет — сначала открой игровой UI) |
| **СОБРАТЬ ЛУТ (эта станция)** | лут из сундука станции → в инвентарь (работает при состоянии Reward) |
| **СОБРАТЬ ВЕСЬ ЛЮТ (все станции)** | то же для всех станций с наградой сразу |

## Порядок теста

1. Зайди в мир → F6 → полистай станции, проверь инфо.
2. Выбери станцию без миссии → **ОТКРЫТЬ UI ЭКСПЕДИЦИИ** — наша панель закрылась,
   игровой UI станции открылся? Выбери миссию (и палов, если хочешь конкретных) → старт.
   Работает ли кнопка на станции, к которой ты НЕ подходил близко?
3. Когда станция вернётся в Ready → **ЗАПУСК — ПОВТОРИТЬ МИССИЮ** → в логе
   `state=InProgress, палов=N`? В игре экспедиция реально бежит?
4. Когда экспедиция завершится (Reward): **СОБРАТЬ ЛУТ** → предметы в инвентаре?
5. Перезаходы в мир, многократные открытия панели, кнопки подряд — крашей быть
   не должно. Если краш всё же случится — запиши, ЧЕМ занимался в этот момент.
