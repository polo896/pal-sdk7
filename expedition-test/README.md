# ExpeditionHubTest v0.2 — мод-пробник системы экспедиций (Palworld 0.4.11, UE4SS Lua)

ТЕСТОВЫЙ мод: разведка перед написанием чистого мода-менеджера экспедиций.
**GUI на F6, только кнопки — консоль не нужна вообще.** Весь вывод проб пишется
прямо в панель (и дублируется в лог UE4SS). Не для публикации.

## Установка

```
Pal\Binaries\Win64\ue4ss\Mods\ExpeditionHubTest\
    enabled.txt
    scripts\main.lua
```

## Панель (F6 открыть / F6 или ESC закрыть)

Сверху вниз:
- **выбор станции** — `<< PREV` / `NEXT >>` (все станции со всех баз сразу);
- **данные выбранной станции** — состояние, миссия, база, таймер, сундук;
- **список миссий** — заполняется кнопкой `MISSIONS`, у каждой кнопка
  `SELECT+START` (выбор миссии → авто-назначение палов → запуск, одной кнопкой);
- **кнопки проб**: `SCAN`, `INFO`, `CHEST`, `UI-PROBE`, `MISSIONS`, `AUTO`,
  `START`, `COLLECT`, `COLLECT ALL`, `REMAIN`, `FB-START`, `GUILD`, `SETTINGS`;
- **лог проб** — последние строки прямо в панели (полный лог — в логе UE4SS).

Панель сама обновляется раз в 3 секунды (таймер тикает).

## Что проверяем (гипотезы из разведки SDK)

| Проба | Что должно получиться |
|---|---|
| `SCAN` | список ВСЕХ станций со всех баз: состояние/миссия/база/координаты |
| `INFO` | дамп станции: id, даты старта/финиша (FDateTime.Ticks) |
| `CHEST` | содержимое сундука станции (лут экспедиции) |
| `UI-PROBE` | **главная проба**: создаётся UI-модель станции, читаются state/таймер/CanStartMission — без репликации и с ней |
| `MISSIONS` | список доступных экспедиций (название, сложность, время, сила, награды) |
| `SELECT+START` | цепочка select → auto → start; station уходит в InProgress |
| `AUTO` / `START` | те же шаги по отдельности |
| `COLLECT` / `COLLECT ALL` | лут из сундука станции падает в инвентарь игрока |
| `REMAIN` | остаток времени двумя способами (из модели и из UI-модели) |
| `FB-START` | фолбэк, если UI-модель не взлетит: ServerInternal напрямую (синглплеер) |
| `GUILD` | сколько экспедиций можно запускать одновременно, что открыто |
| `SETTINGS` | класс функций сортировки (нужен авто-подбору палов) |

## Порядок теста

1. Зайти в мир со станциями экспедиций → F6.
2. `SCAN` → сколько станций, верные ли базы/координаты. Полистай PREV/NEXT.
3. `INFO`, `UI-PROBE` → что показало.
4. `MISSIONS` → список появился в панели? Нажми `SELECT+START` у любой миссии
   на свободной станции → в игре экспедиция реально побежала? (загляни на станцию)
5. Когда экспедиция завершится: `CHEST` (лут в сундуке?) → `COLLECT` →
   предметы появились в инвентаре?
6. `COLLECT ALL` — со всех станций сразу (если несколько с наградой).
7. Если `SELECT+START`/`AUTO`/`START` не сработали — `FB-START` (фолбэк).
8. **Выход в меню → повторный вход в мир → F6 снова** — не крашится? панель живая?
   (главная проверка — у мода с нексуса именно тут краш)

## Безопасность

- только вызовы нативных UFunction (ProcessEvent), без чтений по оффсетам;
- каждый вызов в `pcall` — ошибка не роняет игру;
- между действиями мод ничего не хранит: станции ищутся заново каждый раз;
- UI-модель живёт одно действие: `RequestStartReplication` → действие →
  `RequestStopReplication` → ссылка отброшена (делегаты не висят);
- панель пересоздаётся при каждом открытии и закрывается при смене мира.
