# ExpeditionHubTest v0.3 — мод-пробник системы экспедиций (Palworld 0.4.11, UE4SS Lua)

ТЕСТОВЫЙ мод: разведка перед чистым модом-менеджером экспедиций.
**GUI на F6, только кнопки — консоль не нужна.** Вывод проб пишется прямо в панель
(и в лог UE4SS). Не для публикации.

## Что изменилось в v0.3 (по итогам твоего теста v0.2)

- **Убран 3-секундный авто-рефреш** — именно он «мигал» и крашил игру
  (полная пересборка ~50 виджетов каждые 3 с). Панель обновляется только по
  действиям (кнопка `REFRESH`, PREV/NEXT, любые пробы). Больше не мигает.
- **Заиграли GUILD и SCAN** (уже работали), а вот свежая UI-модель станции
  оказалась НЕ привязанной (GUID пустой) — все Request* уходили в никуда.
- **Три новых пути запуска**:
  1. **ЗАХВАТ** — открой UI станции в игре (подойди, нажми F). Мод перехватит
     игровую, уже привязанную UI-модель → AUTO / START / MISSIONS идут через неё.
     В панели появится «UI-МОДЕЛЬ ИГРЫ: ЗАХВАЧЕНА».
  2. **FB-START с настоящим playerId** (PalPlayerState:GetPlayerId()) — в v0.2
     посылался 0, потому ServerInternal и молчал.
  3. **OPEN-GAME-UI** — дёргает OnTriggerInteract станции: откроется ли игровой
     UI экспедиции удалённо.
- Сундук станции теперь читается и напрямую (поле TargetContainer).
- Таймер читается из UI-модели (GetRemainMissionSeconds), а не из FDateTime
  (у того нет отражённых полей — тот путь был мёртвый).

## Порядок теста v0.3

1. Зайди в мир, F6 → `SCAN` (в логе будет `playerId: N` — важно!).
2. Выбери станцию, у которой указана миссия (не None) → жми `FB-START`.
   Смотри лог: назначились ли палы, ушёл ли state в InProgress. Проверь в игре.
3. Если FB-START молчит:
   - подойди к станции и открой её UI в игре (обычное F) — в панели появится
     «ЗАХВАЧЕНА игровая UI-модель» и строка «>>> привязана к станции …»;
   - закрой игровой UI, вернись в панель (F6) → `MISSIONS` → список должен
     заполниться → жми `SELECT+START` у любой миссии;
   - или попробуй `OPEN-GAME-UI` из панели — открылся ли игровой UI станции?
4. Когда какая-нибудь экспедиция завершится (state = Reward):
   `CHEST` → лут в сундуке? → `COLLECT` → предметы в инвентаре?
5. **Выход в меню → вход в мир → F6** — не крашит? (таймер-краш убран, теперь
   проверяем чистоту захвата UI-моделей)

## Кнопки

`SCAN` `REFRESH` `INFO` `CHEST` | `UI-PROBE` `MISSIONS` `AUTO` `START` |
`COLLECT` `COLLECT ALL` `REMAIN` `FB-START` | `OPEN-GAME-UI` `GUILD` `SETTINGS`

`UI-PROBE` теперь показывает и свежую модель, и захваченную (если есть) —
сравни GUID: у захваченной он должен быть НЕ нулевой.

## Безопасность

- только нативные UFunction (ProcessEvent), всё в pcall;
- станции ищутся заново при каждом действии;
- захваченные UI-модели хранятся только до смены мира (сбрасываются хуком);
- никаких фоновых таймеров, пересобирающих UI.

## Удаление

Снести папку `Mods/ExpeditionHubTest`.
