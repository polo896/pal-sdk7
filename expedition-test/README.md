# ExpeditionHubTest v0.5 — менеджер экспедиций (Palworld 0.4.11, UE4SS Lua)

**F6 — панель. 4 кнопки + список миссий.** Не для публикации (тестовая стадия).

## Что изменилось в v0.5

- **УДАЛЕНО открытие игрового UI через OnTriggerInteract** — оно было источником обоих
  багов v0.4: игра открывала UI без захвата мыши (управление уходило персонажу) и
  оставляло грязное состояние, которое крашило игру при перезаходе в мир.
- **Выбор миссии теперь полностью из нашей панели.** У игры есть свои ЖИВЫЕ
  привязанные UI-модели (WorldHUD-индикаторы станций, создаются на весь сеанс) —
  мод находит их заново при каждом клике, использует и НЕ хранит.
- Список миссий читается даже без привязки (гильдейский список).
- Пассивный хук на серверную функцию выбора миссии: если ты выберешь миссию
  у станции в игре сам — мод записывает формат архива (план Б на случай,
  если живые модели не сработают).

## Установка

```
Pal\Binaries\Win64\ue4ss\Mods\ExpeditionHubTest\
    enabled.txt
    scripts\main.lua
```

(перезапиши `scripts\main.lua`)

## Панель (F6)

- `<< PREV` / `NEXT >>` — выбор станции (все базы), инфо: состояние/миссия/база/палы/сундук
- **ВЫБРАТЬ МИССИЮ** — загружает список экспедиций в панель (сложность/время/сила)
- В списке — кнопка **ВЫБРАТЬ** у каждой миссии (текущая подсвечена золотом)
- **ЗАПУСК МИССИИ** — авто-палы + старт выбранной миссии, не подходя к станции
- **СОБРАТЬ ЛУТ** / **СОБРАТЬ ВСЁ** — лут из сундуков станций в инвентарь (при Reward)

## Порядок теста

1. F6 → полистай станции → **ВЫБРАТЬ МИССИЮ** → список появился?
2. Жми **ВЫБРАТЬ** у любой миссии → в логе «TargetMissionId теперь: …» — сменилась?
   (в логе также будут строки про «привязанные UI-модели» — пришли их целиком)
3. **ЗАПУСК МИССИИ** → `state=InProgress, палов=N`?
4. При Reward → **СОБРАТЬ ЛУТ** → предметы в инвентаре?
5. Перезаходы в мир, открытие/закрытие панели много раз — крашей быть не должно.
6. (Опционально) подойди к станции, выбери миссию в игровом UI — в логе появится
   дамп архива `[hook] выбор миссии в игре: … байт: …` — пришли его.
