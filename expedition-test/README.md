# ExpeditionHubTest v0.11 — менеджер экспедиций (Palworld 0.4.11, UE4SS Lua)

**F6 — панель. Полный цикл из панели: выбор миссии → назначение палов (вручную из
Palbox или AUTO) → запуск → сбор лута.** Игровой UI станции не открывается вообще.
Не для публикации (тестовая стадия).

**Полный цикл подтверждён живым тестом v0.9.** Проблема v0.10: краш 0x10 от
перерисовки (не от скорости кликов — от количества пересборок).

## Что изменено в v0.11 (главное — архитектура UI)

**Краш 0x10 вылечен архитектурно: панель больше НИКОГДА не пересобирается.**

- Раньше каждый клик (и каждое подтверждение действия) делал `ClearChildren` +
создание ~40 виджетов заново — фликер, а через несколько пересборок нативный
краш 0x10 (клик попадал в уничтожаемый виджет, анимации кнопок ссылались на
мёртвые объекты). Троттлинг в v0.10 лишь замедлил накопление.
- Теперь (по схеме из example-of-how-to-create-a-UI, своим кодом):
  - `buildView()` строит ВСЁ один раз при открытии панели (открытие по F6
    никогда не крашило);
  - `refreshView()` обновляет ТОЛЬКО на месте: `SetText`, `SetVisibility`,
    смена цвета текста, перебинд обработчика клика (`Handlers[key]`) —
    **ноль destroy между открытием и закрытием**;
  - смена станции / режима / страницы — это просто refreshView, без пересборки;
  - клики по кнопкам подписаны один раз, обработчик берётся из таблицы в
    момент клика;
  - фликера больше нет в принципе — текст просто меняется.

Прочее (унаследовано из v0.10): полный английский UI, лог в пределах окна,
«Unnamed base» вместо японского плейсхолдера, остаток времени экспедиции.

```
Pal\Binaries\Win64\ue4ss\Mods\ExpeditionHubTest\
    enabled.txt

```

(перезапиши `scripts\main.lua`)

## Панель (F6)

- `<< PREV` / `NEXT >>` — станция; инфо: STATE, MISSION, BASE, PALS, CHEST,
  element, power, reward %, left (при InProgress).
- **AUTO PALS** · **START** · **COLLECT** · **COLLECT ALL**.
- Список: **MODE: MISSIONS / PALBOX / ASSIGNED** (клик по заголовку — обновить),
  SELECT / +ADD / −REMOVE, REMOVE ALL / CANCEL EXPEDITION, `< PAGE` / `PAGE >`.
- LOG (последние строки, цвет по типу).

## Что протестировать

1. Кликай SELECT по миссиям сколько угодно (в т.ч. быстро) — ни фликера, ни
   краша. Переключай станции/режимы/страницы.
2. **Ручная цепочка**: SELECT миссии → MODE: PALBOX → `+ ADD` пала →
   MODE: ASSIGNED (пал в списке?) → START → Reward → COLLECT.
3. `− REMOVE` одного пала, REMOVE ALL, CANCEL EXPEDITION.
4. Перезаход в мир при открытой/закрытой панели.

## Удаление

Снести папку `Mods/ExpeditionHubTest`.
