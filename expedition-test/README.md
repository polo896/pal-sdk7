# ExpeditionHubTest v0.8 — менеджер экспедиций (Palworld 0.4.11, UE4SS Lua)

**F6 — панель. Полный цикл из панели: выбор миссии → назначение палов (вручную из
Palbox или АВТО) → запуск → сбор лута.** Игровой UI станции не открывается вообще.
Не для публикации (тестовая стадия).

## Что починлено в v0.8 (по итогам живого теста v0.7)

Тест v0.7 дал решающие данные: хуки заработали и поймали **ванильные эталоны**
байтов архива (когда сам выбираешь миссию/снимаешь пала у станции в игре), АВТО
подтверждён (0 → 6 палов), но выбор миссии из панели снова крашил 0x70.

Разбор показал: крашил **сам вызов** `WriteBlackboard` на CDO (лог обрывался
после «ВЫБОР миссии», до строки «WriteBlackboard … ок»). Поэтому в v0.8:

1. **Вызовы игровых статических сериализаторов (WriteBlackboard /
   WritePlayerFeedItemTo) полностью удалены** — они крашат 0x70 (ref-параметр
   архива). Байты архива теперь собираются **чистым Lua** по форматам, которые
   дали ванильные дампы из хуков:
   - **FName** → `int32(len+1) + UTF-16LE + L'\0'`
     («DUNGEON_GRASS» → `0E 00 00 00 44 00 55 00 … 53 00 00 00`, 32 байта);
   - **FPalInstanceID пала** → пустой FString DebugName (`00 00 00 00`) +
     PlayerUId GUID (16 байт raw LE) + InstanceId GUID (16 байт raw LE) = 36 байт.
2. Перебор «раскладок» при добавлении пала заменён одним подтверждённым форматом.
3. Наши вызовы видны в хуках — можно сверить байты с ванильными прямо в логе.

## Панель (F6)

- `<< PREV` / `NEXT >>` — выбор станции (все базы); инфо: состояние, миссия, база,
  палы, сундук, требование стихии, сила команды, % награды.
- Кнопки: **АВТО-ПАЛЫ** · **ЗАПУСК** · **СОБРАТЬ ЛУТ** · **СОБРАТЬ ВСЁ**.
- Блок списка, 3 режима (стрелки `<` `>` в шапке блока; клик по «РЕЖИМ: …» — обновить):
  - **МИССИИ** — экспедиции (сложность, время, сила, стихия×N, макс. палов), ВЫБРАТЬ;
  - **PALBOX** — палы по убыванию силы, «+ ДОБАВИТЬ» (помечены «на экспедиции»/«искл.»);
  - **НАЗНАЧЕНЫ** — состав станции, «− СНЯТЬ»; внизу «СНЯТЬ ВСЕХ», а при идущей
    экспедиции — «ОТМЕНИТЬ ЭКСПЕДИЦИЮ».
- `< СТР` / `СТР >` — страницы списка.

## Порядок теста

1. После загрузки мира в логе должны быть 4 строки «hook установлен».
2. F6 → выбери станцию (в инфо должно быть **Ready**).
3. Режим **МИССИИ** → **ВЫБРАТЬ** → в логе: «архив миссии (32 байт): 0E 00 00 00
   44 00 …» и «ГОТОВО: миссия выбрана через архив»?
4. Режим **PALBOX** → **+ ДОБАВИТЬ** пала → «архив(36 байт): 00 00 00 00 …» и
   «ГОТОВО: пал добавлен»?
5. Смотри «стихия: … n/N» и «награда: X%» в инфо станции → **ЗАПУСК** → InProgress?
6. При Reward → **СОБРАТЬ ЛУТ** → предметы в инвентаре?
7. Перезаходы в мир, открытие/закрытие панели — крашей быть не должно.
8. Если что-то не сработало — пришли из лога пары строк: наши («архив миссии … /
   добавить пала: архив …») и хуковые («>>> [hook] …») — сравню форматы.
