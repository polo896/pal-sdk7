# ExpeditionHubTest v0.10 — менеджер экспедиций (Palworld 0.4.11, UE4SS Lua)

**F6 — панель. Полный цикл из панели: выбор миссии → назначение палов (вручную из
Palbox или AUTO) → запуск → сбор лута.** Игровой UI станции не открывается вообще.
Не для публикации (тестовая стадия).

**Полный цикл подтверждён живым тестом v0.9:** выбор миссии через архив, авто- и
ручные назначения, запуск на нескольких станциях, сбор лута (по одной и «COLLECT
ALL»), перезаходы в мир — стабильно.

## Что изменено в v0.10 (по итогам живого теста v0.9)

1. **Фикс краша 0x10 при быстрых кликах** («щёлкал по ВЫБРАТЬ туда-сюда — GUI
   фликало — на 4-й раз краш»). Причина: каждый клик делал ПОЛНУЮ пересборку
   панели (уничтожение + создание ~40 виджетов) — при быстрых кликах клик
   попадал в уничтожаемый виджет. Теперь:
   - кнопки-действия (SELECT / ADD / REMOVE / AUTO / START / COLLECT / CANCEL)
     **не перерисовывают панель мгновенно** — панель обновляется один раз, когда
     действие завершилось и сервер подтвердил результат (~0.6–0.8 с);
   - вся отрисовка идёт через `RequestRender` с троттлингом: не чаще раза в
     250 мс, слипшиеся запросы объединяются в один;
   - навигация (станция/режим/страница) обновляется сразу, но через тот же
     троттлинг.
2. **Полный английский язык** — вся панель и все логи (аудитория Nexus).
   Кнопки: AUTO PALS · START · COLLECT · COLLECT ALL; режимы: MODE: MISSIONS /
   PALBOX / ASSIGNED; строки: STATE / MISSION / BASE / PALS / CHEST / element /
   power / reward / left.
3. **Фикс вылезания лога за пределы окна** — рисовалось 20 строк в бокс на 10;
   теперь показывается столько строк, сколько реально влезает.
4. **«新規生成拠点テンプレート名0(仮)»** — это ИМЯ ТВОЕЙ БАЗЫ из игровых данных:
   японский плейсхолдер разработчиков («имя шаблона новой базы, (временно)») —
   база была создана из шаблона и никогда не переименовывалась (в игре она так
   же и называется). В панели теперь показывается как **Unnamed base**
   (переименуй базу в игре — появится настоящее имя).
5. **Остаток времени экспедиции** — при state=InProgress в шапке появляется
   `left: 1h 23m` (через GetRemainMissionSeconds привязанной модели).

## Панель (F6)

- `<< PREV` / `NEXT >>` — выбор станции (все базы); инфо: STATE, MISSION, BASE,
  PALS, CHEST, element, power, reward %, left (при InProgress).
- Кнопки: **AUTO PALS** · **START** · **COLLECT** · **COLLECT ALL**.
- Блок списка, 3 режима (`<` `>` в шапке блока; клик по «MODE: … ⟳» — обновить):
  - **MODE: MISSIONS** — экспедиции (сложность, время, power, стихия×N, max), SELECT;
  - **MODE: PALBOX** — палы по убыванию силы, `+ ADD` («BUSY» = на экспедиции);
  - **MODE: ASSIGNED** — состав станции, `− REMOVE`; внизу REMOVE ALL, а при
    идущей экспедиции — CANCEL EXPEDITION.
- `< PAGE` / `PAGE >` — страницы списка; внизу — LOG (последние строки).

## Что ещё протестировать

1. **Краш-кейс v0.9**: быстро покликать SELECT по разным миссиям туда-сюда —
   фликера быть не должно, краша быть не должно.
2. **Ручное добавление пала** (MODE: PALBOX → `+ ADD`) — ещё ни разу не
   тестировалось живьём! (формат байтов тот же, что у миссии — должен работать).
3. `− REMOVE` одного пала и REMOVE ALL.
4. CANCEL EXPEDITION при идущей экспедиции.
5. Награда при InProgress — в шапке видно `left: …`.
6. Переименуй базу в игре — в панели появится настоящее имя вместо Unnamed base.
